In this assignment, I analyzed the performance of a binary classification model using penguin prediction data. The dataset includes the model-predicted probability that an observation is female, the predicted class, and the actual sex of each penguin. The dataset provides an opportunity to understand how changing the probability threshold affects classification results and model performance.

My plan for this assignment is to first explore the distribution of the actual classes and calculate the null error rate to establish a baseline for model performance. I will then use probability thresholds of 0.2, 0.5, and 0.8 to create predicted classes and construct confusion matrices containing True Positives, False Positives, True Negatives, and False Negatives. I will use these values to calculate accuracy, precision, recall, and F1 score for each threshold. Finally, I will compare the results and explain how different thresholds can be useful in different real-world situations.
