# Week 2 – Data Acquisition & Management

## Overview

This week focuses on collecting, managing, storing, and analyzing data using different data science tools and techniques.

For this assignment, I worked with a movie-rating dataset collected through Google Forms. The data was organized and stored using PostgreSQL and SQL, then connected to R for data analysis and visualization.

## Data Source

The data was collected using Google Forms.

Participants were asked to rate selected movies on a scale from 1 to 5.

The rating scale was:

- 1 – Very Poor
- 2 – Poor
- 3 – Average
- 4 – Good
- 5 – Excellent

## Tools Used

- Google Forms – Data collection
- PostgreSQL – Data storage and management
- SQL – Data querying and preparation
- R – Data analysis
- ggplot2 – Data visualization
- Quarto – Assignment documentation and reporting

## Research Questions

1. Which movies receive the highest average ratings?
2. Which participants provided the most movie ratings?
3. Which movie genres receive the highest average ratings?
4. How does the number of ratings differ across movies?
5. Is there a relationship between movie popularity and average rating?

## Data Analysis

The analysis was conducted in R after the data was stored and managed using PostgreSQL.

The analysis included:

- Calculating the average rating for each movie
- Counting the number of ratings submitted by each participant
- Calculating average ratings by genre
- Comparing the number of ratings across movies
- Examining the relationship between movie popularity and average rating

## Conclusion

This project demonstrates how data can be collected using Google Forms, organized and managed using PostgreSQL and SQL, and then analyzed and visualized in R. The project provided practical experience working with a complete data workflow from data collection to analysis.
